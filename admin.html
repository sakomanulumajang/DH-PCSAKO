Koneksi ke Google Apps Script
Mode Lokal — data tersimpan di browser ini.

Kosongkan untuk menggunakan mode lokal (localStorage).

Cara Mendapatkan URL GAS
  1. Buka script.google.com dan buat project baru
  2. Salin isi file gas/Code.gs ke editor GAS
  3. Jalankan fungsi init() untuk menyiapkan spreadsheet otomatis
  4. Klik Deploy → New deployment
  5. Pilih tipe: Web App
  6. Set Execute as: Me
  7. Set Who has access: Anyone
  8. Klik Deploy → salin URL yang muncul
  9. Paste URL di kolom di atas → klik Simpan URL
⚠️ Penting: Setiap kali kode GAS diubah, buat deployment baru (bukan edit yang lama). URL deployment lama tetap berfungsi hingga Anda menghapusnya.
Setup Spreadsheet GAS

Buat struktur sheet (Setting, Kegiatan, DataHadir) secara otomatis di Google Spreadsheet yang terhubung. Aman dijalankan berulang kali — tidak menimpa data yang sudah ada.
